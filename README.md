# Document Management Tool

This repository contains a Java document management system and was automatically exported from the Google Code project `document-management-tool`.

## Repository layout

The application is under `document-management-system/`. Its `pom.xml` defines a Maven project, and Java code in the `com.bharat.dms` namespace includes document data-access classes and metadata domain objects.

## Working with the project

Start by reviewing the subproject's Maven manifest and source tree. Use a JDK and Maven release compatible with its declared dependencies and plugins. Database, application-server, and other runtime requirements should be established from the existing project configuration before deployment. Keep environment-specific credentials out of documentation and commits.
